# 行为沙箱使用说明（单样本 + 全自动批量）

静态扫描靠"看代码/特征"判断，难免有看不清的（加壳、加密、混淆）。行为沙箱是把文件
**放进一个一次性、与真机完全隔离的 Windows 沙箱里真的跑一遍**，观察它到底干了什么。
本工具提供两种用法：**全自动批量分析**（推荐）与**单样本交互观察**。

## 一、它能观察到什么

| 项目 | 说明 |
|---|---|
| 新进程 | 监控期间新起的进程及其**完整命令行**（例如偷偷拉起的 `powershell -windowstyle hidden ...`） |
| 落地文件 | 样本写入/生成的文件，自动复制到 `artifacts\` 并算 **SHA256** |
| 持久化 | 新增的开机自启动项（注册表 `Run` / `RunOnce`）、计划任务、服务 |
| 网络 | **按样本进程归因**的出站连接尝试：远端 IP / 端口 / 连接状态，并能指出是哪个样本进程发起的（需开启网络，默认关闭） |
| 报告 | 文字报告 `behavior_report.txt` + 机器可读 `behavior_report.json` |

## 二、前置条件

- Windows 10/11 **专业版/企业版/教育版**（家庭版没有 Windows 沙箱）。
- "Windows 沙箱"功能已启用。若未启用，以管理员身份运行并重启：
  ```
  Enable-WindowsOptionalFeature -Online -FeatureName Containers-DisposableClientVM -All
  ```

## 三、怎么用

### 方式 A：全自动批量分析（推荐）

先用静态扫描**选靶**，再把高危/疑似样本逐个丢进沙箱真跑，最后把**静态结论 + 动态行为**
合并成最终结论，输出汇总报告。

启动方式（三选一）：

1. **双击 `自动行为分析.cmd`**，按提示输入要分析的 文件 或 目录 路径
   （可直接把文件/文件夹拖到该图标上放开，也可粘贴路径）。默认最多分析 5 个样本。
2. 从主扫描器进入：双击 `scan.exe` → 菜单 **4. 行为沙箱分析** → 输入路径。
3. 命令行：

```powershell
# 分析一个目录（默认最多取 10 个高危/疑似样本）
.\auto_analyze.ps1 -Target "C:\样本文件夹"

# 只分析前 3 个，并放通沙箱网络以观察外联
.\auto_analyze.ps1 -Target "C:\样本文件夹" -Top 3 -Network

# 不做静态选靶，直接把目录里所有可执行/脚本类文件都跑一遍
.\auto_analyze.ps1 -Target "C:\样本文件夹" -NoStatic -All

# 复用某次已有的扫描日志选靶
.\auto_analyze.ps1 -ScanCsv "C:\样本文件夹\scan_log_20261016_223750.csv" -Top 20

# 断点续跑：已分析过的样本默认命中缓存、直接复用，不重复开沙箱
```

参数：

| 参数 | 默认 | 说明 |
|---|---|---|
| `-Target` | 必填 | 文件或目录 |
| `-ScanCsv` | 空 | 直接复用已有的扫描日志（CSV）选靶 |
| `-Top` | 10 | 最多分析几个样本（按静态风险分从高到低） |
| `-Verdicts` | HIGH,SUSPICIOUS,PACKED,SKIP | 静态命中哪些判定才进入动态分析 |
| `-Exts` | 全部 | 只分析指定扩展名（逗号分隔），如 `-Exts .exe,.ps1`；配合 `-Verdicts NORMAL` 可专门复核静态漏报 |
| `-All` | 关 | 忽略 `-Top`，分析所有候选 |
| `-NoStatic` | 关 | 不调用扫描器，直接把目录内可执行/脚本类文件作为样本 |
| `-Network` | 关 | 沙箱内放通网络；**只记录样本进程树发起的 TCP 连接**（远端 IP / 端口 / 状态），系统自身流量会被精确过滤 |
| `-TimeoutSeconds` | 45 | 单个样本观察时长（秒） |
| `-WaitMinutes` | 8 | 单个样本最多等报告多久 |
| `-ScannerDir` | 自动查找 | 指定扫描器目录（含 scan.exe + scaler.txt） |
| `-OutDir` | `分析结果` | 汇总报告输出目录 |
| `-KeepWork` | 关 | 保留临时工作目录（排错用） |

**结论如何合并**（动态优先）：

| 静态 | 动态 | 最终结论 |
|---|---|---|
| 任意 | 动态确认恶意行为 | **动态确认恶意**（最可信） |
| 高危 | 动态未见 | 静态判高危，动态未复现（可能需特定环境/网络） |
| 正常 | 动态确认恶意 | **动态确认恶意**（静态漏报，动态抓住） |
| 加壳/无法识别 | 动态未见 | 无法判定，仍建议谨慎 |

**行为打分**（0–100）：≥55 = 确认恶意行为；≥22 = 可疑行为；否则 = 未见明显恶意行为。
命中的行为规则（节选）：
- 拉起 `powershell -enc/-windowstyle hidden`、`mshta`、`rundll32`、`regsvr32`、`certutil`/`bitsadmin` 下载
- 新增注册表 `Run` 自启动、计划任务、服务
- 往启动文件夹投放、落地可执行文件、样本自我复制到其它位置
- 删除卷影副本（勒索特征）、`cipher /w` 擦除磁盘
- 出站网络连接

### 方式 B：单样本交互观察

想"亲眼看"某个样本干了什么时用。

**双击 `行为沙箱.cmd`**，输入样本路径，选择是否开启网络即可。命令行：

```powershell
# 观察单个样本（网络默认关闭，更安全）
.\sandbox_run.ps1 -Sample "C:\某个样本.exe"

# 观察整个目录里的样本
.\sandbox_run.ps1 -Sample "C:\样本文件夹"

# 想看它连向哪里（沙箱内联网，仍在隔离环境里）
.\sandbox_run.ps1 -Sample "C:\某个样本.exe" -Network

# 只生成沙箱配置，先不启动
.\sandbox_run.ps1 -Sample "C:\某个样本.exe" -NoLaunch
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `-Sample` | 必填 | 样本文件或目录 |
| `-TimeoutSeconds` | 60 | 样本运行观察时长（秒） |
| `-Network` | 关 | 是否在沙箱内放通网络（观察外联用） |
| `-WaitMinutes` | 8 | 宿主最多等报告多久 |
| `-NoLaunch` | 关 | 只生成 `.wsb` 配置，不启动沙箱 |

## 四、输出在哪

- 单样本：`reports\<样本名>_<时间戳>\`
  - `behavior_report.txt` —— 给人看的报告
  - `behavior_report.json` —— 给程序解析（`schema` 字段是报告格式版本，当前为 `5`；`5` 起新增 `network_events`）
  - `behavior_report.xml` —— CLIXML 兜底格式（跨 PowerShell 版本最稳）
  - `artifacts\` —— 被样本落地出来的文件（含 SHA256）

- 全自动批量：`分析结果\`
  - `自动分析报告_<时间戳>.md` —— 汇总报告（结论一览表 + 逐样本明细 + 原始报告折叠块）
  - `结论_<时间戳>.csv` —— 结论表格（方便导入表格软件）

## 五、它做了什么（原理）

1. 宿主脚本把样本拷进临时目录，生成一个 `.wsb` 配置：
   - 样本目录只读映射到沙箱 `C:\Samples`
   - 结果目录可写映射到沙箱 `C:\Out`
   - 登录时自动运行 `guest_monitor.ps1`
2. 沙箱内监控脚本：先给"进程/文件/注册表"拍快照 → 运行样本 → **每 250ms 高频轮询**
   新进程（取完整命令行）→ 观察一段时间 → 再拍一次 → 求差集。
   开启网络时（`-Network`）另有一条**网络归因**线：约每秒对"样本进程树"里的每个 PID 执行
   `Get-NetTCPConnection -OwningProcess <PID>`，抓该进程自己的远端 IP / 端口 / 连接状态，
   写进报告的 `network_events` 数组。因为只查样本进程树里的 PID，系统基线流量（DNS 客户端、
   Windows Update 等）不会混进来。
3. 报告写回可写的映射目录，宿主自动回收、存档、打印。
4. 观察结束后由宿主**强制关闭**沙箱（一次性，关闭即销毁）。

## 六、安全与局限

- **安全**：样本只在沙箱里运行，与真机文件系统/注册表隔离；默认断网；关闭沙箱即全部销毁。
  即便样本是勒索软件，也动不了你的真实文件。
- **局限**：
  - 沙箱内是干净系统，**看不到"针对特定环境才发作"的样本**（有的恶意软件会检测并装死）。
  - **下载器 / 远控类样本默认断网时会"静默"**：它们要连上 C2 才会下载载荷、落地、外联。
    这类样本断网跑往往什么都不做（例如本样本集里的 WebDAV/HTTP 加载器、部分 RAT）。
    想看到它们的行为，需要 `-Network`。开网后本工具会按**进程**归因（报告的 `network_events` 字段），
    系统自身流量已被过滤，因此"哪个样本进程连了哪个 IP:端口"是可信的；但它仍是
    **约每秒一次的定点采样**，抓不到完整流量，秒级闪现的连接也可能漏掉。
  - 沙箱里没装办公软件等依赖，打开 `.doc/.xls/.pdf` 类样本可能没有关联程序。
  - 网络观察是"连接尝试"，不是完整流量抓包。
  - 需要交互式的桌面会话才能弹出沙箱窗口。
  - 行为观察有时长限制（默认 45 秒），**延时触发的样本可能来不及暴露**。
- 说明：脚本类样本（`.ps1`/`.hta` 等）由本工具用固定命令拉起（如
  `powershell -ExecutionPolicy Bypass -File <样本>`）。**这条"我方启动命令"不会被计入行为评分**
  （报告里标为"我方启动命令，不计入行为评分"），避免自己吓自己；样本自己再派生出来的进程照常计分。
- 建议：**静态扫描结果 + 行为沙箱结果 一起看**，结论更稳。
