恶意软件扫描器 —— 使用说明
====================================
版本：2026-10-17 夜（【PE 虚拟执行】联动已接入 scan.exe 一般扫描流程：目录/单文件扫完若发现加壳 PE，自动跑用户态 x86 解释器；菜单 5 可开关，命令行 --no-pevm 可关；主引擎逻辑与 scan_any.ps1 共用同一份内核）
工具源目录：F:\SVM项目\04_c

【文件夹里有什么】
  scan.exe                 主扫描器（双击 = 菜单模式）
  stream_scan.exe          管道/流式扫描器（供 scan_any.ps1 使用）
  scan_any.ps1             统一入口：压缩包 / 目录 / 单文件，自动写日志 + 报毒率
  scan_startup.ps1         启动项体检脚本（枚举自启动位置逐个扫描）
  启动项体检.cmd           双击即可跑体检（体检脚本的启动器）
  拖文件到这里扫描.cmd     把目标拖到该文件图标上放开即可扫描
  scaler.txt               模型归一化参数（必须和 exe 放在一起，不要删/改名）
  行为沙箱\               动态行为观察（Windows Sandbox 真隔离，见下）
    行为沙箱.cmd          单样本交互观察（想看某个文件到底干了什么）
    自动行为分析.cmd      全自动批量：静态选靶 → 批量沙箱 → 合并结论（推荐）
  沙箱\PE虚拟执行沙盒\    PE 用户态虚拟执行（pe_vm.exe，不开虚拟机；静态扫不动的加壳 PE 用它还原）
     pe_vm.exe            用户态 x86-32 解释器：指令逐条虚拟执行、API 全假实现，与真机零接触
     pevm_lib.ps1         联动内核：找解释器 / 判 PE 类型 / 跑虚拟执行 / 复扫解壳产物（扫描器与 scan.exe 共用）
     虚拟执行.ps1         scan.exe 扫描收尾自动调用的驱动脚本（也可自己单跑：见下「虚拟执行」段）
  扩展扫描说明.md          完整技术文档（含类型、CARO 映射、编译说明）

【常用方式】
1) 扫单个文件
   双击 scan.exe → 输入 1 回车 → 弹窗选择文件
   或用菜单 3 手动输入文件路径
   （单文件/目录扫完若发现加壳 PE，会自动接着做虚拟执行；菜单 5 可开/关）

2) 扫压缩包 / 文件夹 / 未知文件（推荐）
   把目标拖到「拖文件到这里扫描.cmd」图标上放开
   - 压缩包成员在内存中扫描，不解压落盘（杀软环境也安全）
   - 自动读取 .pass 文件与默认密码（infected / malware / password）
   - 结果同时写入为「目标名.scanlog.txt」（UTF-8）

3) 启动项体检（看看电脑有没有可疑自启动）
   双击「启动项体检.cmd」，一分钟左右出汇总：
   枚举 Run/RunOnce、启动文件夹、计划任务、Winlogon、自动服务，
   逐个扫描，详细日志存为 startup_audit_<时间>.txt

4) 命令行
   scan.exe scaler.txt "文件路径"
   scan.exe scaler.txt "文件夹路径" --log "输出.csv"     ← 目录扫描会递归全部文件
   scan.exe scaler.txt "目标" --no-pevm                  ← 关掉"扫完自动做的虚拟执行"，只做静态
   powershell -File scan_any.ps1 "文件夹路径" -Recurse
   powershell -File scan_any.ps1 "文件夹路径" -Sandbox   ← 扫描后对高危/疑似自动做行为沙箱分析
   powershell -File scan_any.ps1 "文件夹路径" -PevmAll   ← 所有 PE 都做虚拟执行（默认只做加壳的）
   powershell -File scan_any.ps1 "文件夹路径" -NoPevm    ← 关掉虚拟执行，只做静态
   powershell -File scan_startup.ps1

5) 行为沙箱（想知道它到底干了什么时用）—— 两种用法
   A. 全自动批量分析（推荐）：双击「行为沙箱\自动行为分析.cmd」，
      或双击 scan.exe → 菜单 4. 行为沙箱分析，输入 文件/目录 路径。
      它会：先用扫描器静态选靶 → 把高危/疑似样本逐个丢进沙箱真跑 →
      用行为规则打分 → 合并成"最终结论"，并输出 汇总报告(MD) + 结论表(CSV)。
      报告在「行为沙箱\分析结果\」。已分析过的样本会命中缓存、不重复开沙箱。
   B. 单样本观察：双击「行为沙箱\行为沙箱.cmd」，输入样本路径。
   两者都会把样本放进一个一次性、与真机完全隔离的 Windows 沙箱里真的跑一遍，
   记录：新进程（含完整命令行）、落地文件（含 SHA256）、新增开机自启动/计划任务、网络连接尝试。
   详细见「行为沙箱\行为沙箱说明.md」。需要 Windows 专业版/企业版 + "Windows 沙箱"功能。

【输出怎么看】——全中文结果块，每个文件一段
  【文件】      扫描目标
  【类型】      快捷方式（.lnk）/ 文本脚本（PE 不显示此行）
  【数字签名】  有效签名的厂商名（"可信发布者" = 白名单放行）
  【命中特征】  命中的特征码名（如 Phobos_VSSADMIN）
  【检测名】    CARO 技术检测名（如 Rogue.LNK.Promotion）
  【熵值】      内容随机程度，>7 判为疑似加壳
  【风险评分】  ≥80 高危 / ≥50 疑似 / <50 正常
  【判定】      中文判定结论，行尾保留机器标记（脚本计数用，请勿删）：
                [HIGH RISK] / [SUSPICIOUS] / [NORMAL] / [TRUSTED] / [PACKED] / [SKIP]
  【触发规则】  文本脚本命中的具体规则与权重（如"隐藏窗口执行(+25)"）
  【风险名称】  分数达线时输出中文风险名，如"勒索软件脚本"、"推广诱骗快捷方式"
  【建议】      该文件如何处置（隔离 / 谨慎使用 / 可放心使用）

  一句话看结论：行尾 [HIGH RISK] = 高危；[SUSPICIOUS] = 疑似；
  [NORMAL] = 正常；[TRUSTED] = 可信签名；[PACKED] = 疑似加壳；[SKIP] = 无法识别

【虚拟执行】（加壳 PE 的补充结论；scan_any.ps1 与 scan.exe 一般扫描流程都会自动做）
  静态判为 [PACKED] 的 PE 会被送进 pe_vm.exe（用户态 x86 解释器）"跑"一遍：
  指令逐条解释执行、Windows API 全部是假实现，不加载真 DLL、不碰真注册表/网络、
  也绝不执行真实机器码。输出一段补充结论：
    执行情况 : 跑了多少条指令 / 多久 / 因为什么停下
    动态结论 : 恶意行为 或 未见异常 或 无法定论，行尾标记 [VM: …]
    证据     : 企图启动进程 / 注册表敏感项（自启动）/ 网络通信 / 解壳完成(写后执行)
    解壳产物 : 脱出来的载荷会另存到 <目标>\_虚拟执行\ ，并自动再静态复扫一遍
  说明：[VM: …] 是独立标记，不影响上面的 [HIGH RISK] 等机器标记与汇总计数。
  以下三种情况会明确说"为什么不动它"：64 位 PE（x86-32 解释器不支持）、
  .NET 程序集（需 IL 分析）、未能进入样本代码。
  scan_any.ps1 的汇总里会多两行：== 虚拟执行: … == 和 == 动态找回: 静态没报毒、动态确认恶意 N 个 ==。
  scan.exe 则在"扫描统计"块之后单独打印一段 [虚拟执行] 结果，并在
  <目标>\_虚拟执行\虚拟执行报告.txt 留一份完整报告。
  想对某个 文件/目录 单独做一次虚拟执行（不再静态复扫）：
    powershell -File 沙箱\PE虚拟执行沙盒\虚拟执行.ps1 -Target "文件或目录"

【扫描统计（报毒率）】
  目录 / 批量扫描结束时给出统计：文件总数、高危、疑似、正常、可信、加壳、跳过、失败，
  并计算两个报毒率：
    (高危+疑似)/可判定   —— 只看"能判定"的文件（排除跳过）
    (高危+疑似)/全部文件 —— 分母含全部文件（口径更保守）
  若启用了虚拟执行：scan_any.ps1 的汇总末尾会再加两行（虚拟执行 / 动态找回数量）；
  scan.exe 则在统计块之后另起一段 [虚拟执行] 结果（内容同上，只是位置不同）。

【上下文日志（CSV，UTF-8 BOM）】
  目录扫描会在目标目录自动生成 scan_log_YYYYMMDD_HHMMSS.csv，逐文件记录：
    时间, 完整路径, 文件名, 大小(字节), SHA256, 类型, 判定, 评分, 层级, 检测名, 细节
  末尾带一行 # 汇总。也可用 --log <路径> 指定输出位置（单文件也支持）。

【注意】
  1. scaler.txt 必须与本文件夹一起搬走（移动/打包时别落下它）
  2. 本工具只做静态扫描 + 用户态虚拟执行，绝不把样本交给真机运行：
     加壳 PE 的"虚拟执行"是本进程内解释器逐条模拟（Windows API 全是假实现），
     与真机零接触；要"真机隔离里跑一遍"请用"行为沙箱"
  3. 压缩包/目录扫描依赖 7-Zip（默认路径 C:\Program Files\7-Zip\7z.exe）
  4. scan_any.ps1 的目录扫描可加 -Recurse 递归子目录；scan.exe 直接扫目录会递归全部文件
  5. 判决缓存已关闭：每次扫描都重新分析，不跳过之前扫过的文件（结论始终最新）
  6. 微软等大厂签名的正规软件会显示 [TRUSTED]，这是"白名单优先"设计，不是漏报
  7. 结果日志为 UTF-8 编码；若用旧程序打开出现乱码，请改用 VSCode / 新版记事本查看
